Comment résoudre une équation du second degré ?
On utilise le discriminant : Δ = b² − 4ac. Si Δ > 0, deux solutions réelles ; si Δ = 0, une solution double ; si Δ < 0, pas de solution réelle. On veut un exemple ?
Oui, avec x² − 5x + 6.
